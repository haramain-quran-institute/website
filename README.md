# Haramain Quran Institute landing page

A standalone Next.js landing-page template based on the archived Haramain Quran Institute app. It contains a single Quran-focused route and reusable header, footer, button, and free-trial popup components.

## Run locally

```bash
npm ci
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

Import this folder as a Vercel project, or run:

```bash
npx vercel login
npx vercel --prod
```

Vercel automatically detects the Next.js build settings.
